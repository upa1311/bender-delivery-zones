/review/ — тарифная граница на Парканы (Котовского) и расчёт цены

Формула: base = 14 руб. (≤3 км), далее +4 руб./км; внешняя надбавка = max(5, external_km × 2); итог = base + надбавка. Внешняя часть начинается только ПОСЛЕ тарифной границы. Отправление — одна фиксированная точка 46.82388, 29.48313 (архитектура готова к нескольким ресторанам). Маршрут — реальный (OSRM), сверен с контрольным Яндексом ≈ 4.72 км.

1. Перетащите тарифную границу на фактический пост (ул. Котовского)

Красная точка — перемещаемая тарифная граница (PROVISIONAL). Синие точки — кандидаты, где реальный маршрут пересекает городские границы OSM. Ни одна из спорных «координат поста» не принята авторитетной. После перемещения цена пересчитывается мгновенно.

2. Предлагаемые внутренние зоны (по фактическому разбросу цены)

Зоны построены методом естественных границ (Jenks) по цене, не по равным километрам и не по квартилям. Зоны — внутренние (админ/контроль стоимости/ аналитика); клиенту номер зоны не показывается. Внешние территории получат зону после утверждения границы и построения их маршрутов.
