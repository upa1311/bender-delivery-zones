## Как снимать замер (одинаково для каждой строки)

1. Открыть Яндекс Карты, «Маршруты», режим **автомобиль**.
2. Точка А — **46.82388, 29.48313** (не менять между замерами).
3. Точка Б — координаты из строки (`destination_lat`, `destination_lon`).
4. Включить **«Игнорировать текущую дорожную ситуацию»**.
5. Включить **избегать платных дорог**.
6. Посмотреть **все** предложенные варианты.
7. Записать самый быстрый: `yandex_fastest_distance_km`, `yandex_fastest_duration_min`.
8. Если самый короткий разумный вариант отличается — записать его в
   `yandex_alternative_distance_km` / `yandex_alternative_duration_min`.
9. Записать словами: `yandex_main_streets` (основные показанные улицы),
   `yandex_district_entry` (через какой въезд), `yandex_rail_crossing_or_bridge`
   (переезд / путепровод / мост, если есть), `matches_owner_corridor` (да/нет/частично).
10. Проставить `checked_date`.

**Не сохранять** в репозиторий скриншоты, полилинии, тайлы и HTML — только цифры,
названия дорог и собственные выводы.


Заполненные строки попадают в `docs/data/manual-yandex-route-controls.csv`, после
чего `uv run python scripts/manual_yandex_controls.py calibrate` посчитает
расхождение с нашим движком.
