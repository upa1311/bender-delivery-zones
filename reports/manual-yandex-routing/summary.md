# Ручные контрольные маршруты Яндекса — сводка

**Статус: ЗАМЕРЫ НЕ СНЯТЫ (0 из 86).** Read-only: зоны, release, Direct и
цены не менялись до вашего одобрения.

## Почему замеры не сняты мной

Свободный веб-интерфейс Яндекс Карт разрешён вами только как **ручной** источник.
Управление браузером агентом — это автоматический доступ независимо от объёма, а
вы прямо запретили scraping и обход защиты. Поэтому я подготовил всё, кроме самих
измерений: их нужно снять руками.

## Что подготовлено

| район | контрольных маршрутов |
|---|---|
| Хомутяновка | 25 |
| Протягайловка | 20 |
| Гиска | 16 |
| Парканы | 14 |
| Северный | 7 |
| Борисовка | 4 |
| **итого** | **86** |

Каждая строка уже содержит: `control_id`, `uid`, район, улицу, дом, точные
координаты назначения, причину выбора, текущую зону, текущий OSRM км, км нашего
движка и ожидаемый въезд по нашему движку. Пустыми оставлены только те поля,
которые заполняет человек из интерфейса Яндекса.

Выборка по каждому району: 3 ближайших, 3 средних, 3 самых дальних, дома у каждого
известного въезда, дома у текущих границ Zone 2/3 и Zone 3/4, а также
owner-названные улицы и ориентиры (Пивзавод, Молдплодовощ, Роддом, Городская
больница — координаты взяты из локального OSM-экстракта). Для Северного — все 7
точных адресов. Борисовка добавлена ранее проверенными контролями Stage 09C. Обязательная улица без подтверждённых домов (улица Ечина) получила координатный контроль по середине улицы, а не была молча пропущена.

Три owner-названные улицы (Московская, Первомайская, Некрасова) наш районный
ярлык относит к соседним местам — в таблице виден и вычисленный `district`, и
`target_district` владельца. Это само по себе повод для проверки.

## Что запрещено и соблюдено

- автоматический массовый scraping — не выполнялся;
- обход защиты — не выполнялся;
- запросы ко всем 9 216 домам через веб-интерфейс — не выполнялись;
- скриншоты, полилинии, тайлы, HTML Яндекса — в репозиторий не сохраняются;
- предположения как фактические маршруты — не выдаются.

## После заполнения

```
uv run python scripts/manual_yandex_controls.py calibrate
```

Скрипт посчитает `yandex_minus_osrm_km`, отношение, отметит расхождения >10 % как
`ENGINE_DISAGREES_WITH_MANUAL_CONTROL`, соберёт каталог подтверждённых въездов
(`docs/data/manual-yandex-confirmed-entries.csv`) и сравнит его с нашим OSM/OSRM.
Только после этого имеет смысл править маршрутный граф и пересчитывать дома —
зоны остаются неизменными до вашего одобрения.
